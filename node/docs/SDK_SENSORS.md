# SDK 0.4 传感器接入

从采集页左侧添加传感器，再在卡片中配置和连接串口。每张卡片独立连接，同一串口不可被两张卡片同时占用。SDK 模拟源可用于链路测试；人体与鞋垫卡片使用真实产品连接入口。

| 传感器 | 必填配置 | 预览 | 保存数据 |
| --- | --- | --- | --- |
| 手部检测垫 | 串口 | 32×32 映射矩阵 | 1024 uint8 ADC |
| 触觉手套 | 串口、左右手、分包/整包 | SDK 压力矩阵 / 原始 IMU | 256 uint8 ADC + 16 IMU 字节 |
| 人体全身 | 串口 | 10 个物理分区，共 400 点 | 1024 uint8 ADC + 分区源索引 |
| 鞋垫 A 版 | 串口、左右脚、协议、波特率 | 112 个真实点 / 原始 IMU | 256 ADC + 点位坐标/源索引 + IMU |

手套默认使用 0.4.0 分包协议，在 921600 波特率配对 130 字节首包与 146 字节尾包。整包设备需切换到「整包（兼容旧设备）」。`gloveProtocol` 连接参数与鞋垫的 `protocol` 分开，录制的 `metadata.protocol` 明确保存 `segmented` 或 `full-packet`。分包的包类型保存在 `packet_type`，没有设备帧序号时 `sdk_sequence` 为 null；采集服务自己的递增序号不代表设备丢包检测结果。

鞋垫支持 12 bit 整帧与 8 bit 分包，必须与固件一致。默认 12 bit、921600；可选波特率为 921600、1500000、3000000、460800、256000、115200、9600。协议没有可靠脚侧标识，不能自动判断左右脚。

12 bit 压力用 `uint16` 小端保存，保留 0–4095；8 bit 用 `uint8` 保存。对应原始 IMU 分别为 40 和 16 字节。本版保留并展示 IMU 字节，不把缺少明确单位的数据标为加速度或角速度。

连接成功后，人体和鞋垫需要首个有效帧提供完整映射才能开始录制。界面在此期间显示“等待首帧”。若持续无数据，请检查所选串口、鞋垫协议、波特率和实际设备型号。连接或录制期间不能修改这些参数。

人体分区遵循 SDK 物理矩阵的源索引，不擅自交换左右或变成解剖模型。鞋垫使用 SDK 毫米坐标等比例画点，不进行插值、镜像或压力标定。各区共用当前帧的颜色范围，数值单位为 ADC。

录制保留原始通道，映射保存为 `metadata.pressure_layout`。回放按记录时的映射恢复；CSV/NPZ/JSON 等数据包继续附实验信息与标签，NPZ 的 12 bit 数据数组类型为 uint16。旧版录制仍可回放；旧 0.2.0 手垫保留兼容映射。

本次新增产品使用合成契约帧验证了配置传递、完整帧校验、原始数据精度、录制回放与导出。对应固件、实物触点及最高采样率需在实际人体传感器和鞋垫连接后验证。
